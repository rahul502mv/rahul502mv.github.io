# Rahul M — Portfolio

Static portfolio website for Rahul M.

## Included
- Premium dark/futuristic responsive design
- Profile photo
- Data Scientist and Data Analyst resumes
- 4 featured projects
- Experience, education, achievements and certifications
- GitHub, LinkedIn, email and live project links
- Responsive mobile layout
- Scroll reveal animations

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Deploy
This is a static site and can be deployed to GitHub Pages, Netlify, Vercel, or Render Static Sites.
